Cryptomus Setup Guide
Getting Started:
  1. Sign up: Cryptomus Registration
  2. Complete Verification: Verify your email and complete KYC if needed
  3. Get API Keys: Dashboard → API → API Keys → Create New Key
  4. Configure Webhooks: Dashboard → API → Webhooks → Add Webhook
Testing:
  1. Use Test API Keys: Cryptomus provides separate test keys
  2. Test Payments: Use small amounts to test the flow
  3. Check Webhooks: Verify webhooks are being received
  4. Go Live: Switch to live API keys when ready
Important Notes
  • Cryptocurrency payments are irreversible - no chargebacks
  • Fees: 0.4% per transaction (lower for high volume)
  • Automatic conversion to your preferred currency available
  • 24/7 customer support via Telegram and email
  • Monitor exchange rates as crypto prices fluctuate
