Fincra Setup Guide
Sandbox Setup (Testing):
  1. Sign up: Fincra Sandbox
  2. Create Business: Complete business profile setup
  3. Get API Keys: Developers → API Keys → Generate Keys
  4. Configure Webhooks: Developers → Webhooks → Add Endpoint
Live Mode Setup (Production):
  1. Complete KYC: Submit business documents for verification
  2. Get Live Keys: After verification, generate live API keys
  3. Set Settlement Account: Add your bank account for payouts
  4. Go Live: Disable sandbox mode when ready
Important Notes
  • Fincra requires full KYC verification for live transactions
  • Supported currencies depend on your business location
  • Transaction fees vary by payment method and country
  • Test thoroughly with sandbox before going live
