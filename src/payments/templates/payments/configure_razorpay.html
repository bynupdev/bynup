Razorpay Setup Guide
Test Mode Setup:
  1. Sign up: Razorpay Dashboard
  2. Get Test Keys: Settings → API Keys → Generate Test Key
  3. Configure Webhooks: Settings → Webhooks → Add Endpoint
  4. Test: Use test card numbers and UPI IDs
Live Mode Setup:
  1. Complete KYC: Submit business documents for verification
  2. Get Live Keys: After KYC approval, generate live API keys
  3. Update Webhooks: Use live webhook secret
  4. Switch to Live: Disable test mode when ready
