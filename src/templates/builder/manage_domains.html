DNS Configuration Instructions

To use your custom domain, configure these DNS records with your domain provider:

For root domain (mystore.com):
Type Name Value TTL
A @ YOUR_SERVER_IP 3600
CNAME www {{ page.subdomain }}.yourdomain.com 3600
For subdomain (shop.mystore.com):
Type Name Value TTL
CNAME shop {{ page.subdomain }}.yourdomain.com 3600
Note: Replace YOUR_SERVER_IP with your actual server IP address. DNS changes may take up to 24 hours to propagate.
Propagation Time: DNS changes typically take 24-48 hours to fully propagate worldwide. Some ISPs may cache DNS records longer.
